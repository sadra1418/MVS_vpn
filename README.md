# MVS_vpn

نسخه Live Browser.

کاربر وارد `/get_url` می‌شود، آدرس سایت را وارد می‌کند و یک Chromium واقعی روی سرور همان سایت را باز می‌کند.

نمایش صفحه با **Chromium CDP screencast** و انتقال تصویر با **WebSocket** انجام می‌شود. کلیک، حرکت ماوس، اسکرول و کیبورد نیز از مرورگر کاربر به Chromium سرور ارسال می‌شوند.

این معماری با polling اسکرین‌شات یا VNC کار نمی‌کند و برای latency پایین طراحی شده است.

## اجرا

```bash
docker build -t mvs-vpn .
docker run -p 10000:10000 mvs-vpn
```

بعد:

http://localhost:10000/get_url

## نکته

این نسخه تصویر و ورودی تعاملی مرورگر را منتقل می‌کند. انتقال صدای سیستم یا صدای ویدئو، مثل YouTube، یک مسیر جدا از تصویر است و با CDP screencast به‌تنهایی منتقل نمی‌شود.
