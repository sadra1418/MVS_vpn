# MVS_vpn

ابزار ساده برای باز کردن **هر سایتی** با IP سرور (مثل VPN شخصی).

فقط صفحهٔ سایت هدف در UI نمایش داده می‌شود.

## تغییر سایت (مهم)

فایل `config.py` را باز کن و فقط این خط را عوض کن:

```python
TARGET_URL = "https://gemini.google.com"
```

هر سایتی که بخوای می‌تونی بذاری (مثلاً deepseek، chatgpt، یا هر چیز دیگه).

## دو روش استفاده

### روش ۱: وب‌سرور ساده (Docker)

```bash
docker build -t mvs-vpn .
docker run -p 10000:10000 mvs-vpn
```

بعد برو به: `http://IP-سرور:10000`

این روش صفحه را در iframe نشان می‌دهد. بعضی سایت‌ها iframe را بلاک می‌کنند.

### روش ۲: مرورگر واقعی روی سرور (IP واقعی سرور)

اگر می‌خوای واقعاً با IP سرور وارد سایت شوی (برای سایت‌هایی که IPت را محدود کرده‌اند):

```bash
pip install -r requirements.txt
playwright install chromium
python open_browser.py
```

این روش یک مرورگر واقعی روی سرور باز می‌کند و با IP سرور کار می‌کند.

---

هر وقت سایت را عوض کردی فقط `TARGET_URL` را تغییر بده.
