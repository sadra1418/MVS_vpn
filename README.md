# MVS_vpn

ابزار ساده برای باز کردن **هر سایتی** با IP سرور (مثل VPN شخصی).

فقط صفحهٔ سایت هدف در UI نمایش داده می‌شود. هیچ چیز اضافه‌ای نیست.

## نحوه استفاده

1. فایل `config.py` را باز کن و آدرس سایت مورد نظرت را بگذار:

```python
TARGET_URL = "https://gemini.google.com"
```

هر سایتی که بخوای می‌تونی بذاری.

2. با Docker اجرا کن:

```bash
docker build -t mvs-vpn .
docker run -p 10000:10000 mvs-vpn
```

سپس به آدرس سرور برو: `http://IP-سرور:10000`

## تغییر سایت

فقط `TARGET_URL` را عوض کن و دوباره build بگیر.
